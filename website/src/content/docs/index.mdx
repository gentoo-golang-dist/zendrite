Zendrite is an efficient, reliable, and scalable Matrix homeserver written in Go.
It advertises Matrix spec versions up to v1.19, and [MSC support](/mscs) lists the proposals it implements.

This site documents how to install and run Zendrite:

- **[Installation](/installation/planning)**: build and deploy your own Zendrite homeserver.
- **[Administration](/administration/createusers)**: manage an existing Zendrite deployment.
- **[Development](/development/contributing)**: develop against Zendrite.

If you have a question, check [the FAQ](/faq).
